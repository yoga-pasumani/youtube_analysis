# youtube_analysis

This notebook explores a dataset of YouTube creators, analyzing trends, performance metrics, and correlations between different engagement factors.

## Key Analyses Performed

- **Data Cleaning**: Handled missing values and checked for duplicates
- **Outlier Detection**: Visualized rank distribution to identify anomalies
- **Category Analysis**: Identified most popular categories by subscriber count
- **Engagement Metrics**: 
  - Correlation analysis between subscribers, likes, and comments
  - Distribution analysis of channel visits
- **Performance Benchmarking**:
  - Compared average metrics across all channels
  - Identified top-performing categories
  - Found channels performing above average in all key metrics

## Visualization Highlights

1. Category popularity by subscribers
2. Correlation heatmap of engagement metrics
3. Distribution of channel visits
4. Subscribers vs. brand collaborations scatter plot

## Requirements

- Python 3
- pandas
- seaborn
- matplotlib
- plotly (for the histogram visualization)
